# Retail Sales Performance Dashboard

## Project Overview

This project analyzes over 10,000 retail sales records to identify revenue trends, profit patterns, and regional performance gaps using Microsoft Excel. The dashboard provides interactive insights that help stakeholders monitor business performance and make data-driven decisions.

## Objectives

* Analyze sales and profit performance across regions.
* Identify top-performing products and categories.
* Track revenue trends over time.
* Highlight regional performance gaps.
* Create an interactive dashboard for business reporting.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Conditional Formatting
* SUMIFS
* COUNTIFS
* INDEX-MATCH
* XLOOKUP

## Key Features

* Built a dynamic dashboard with interactive slicers.
* Created Pivot Tables and Pivot Charts for sales analysis.
* Analyzed revenue, profit, and regional performance.
* Consolidated data from multiple sources into a single reporting view.
* Improved reporting efficiency by reducing manual analysis efforts.

Key Insights

* Identified revenue and profit trends across different regions.
* Highlighted top-performing products and categories.
* Detected underperforming regions requiring business attention.
* Enabled quick decision-making through dashboard visualizations.

Project Files

* Retail Sales Dashboard.xlsx
* Dataset.xlsx
* Dashboard Screenshots
